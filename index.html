🛠 Azure App ID setup

One-time setup (~10 mins):

  1. Go to portal.azure.com
  2. Search App registrations → New registration
  3. Name: Mileage Logger
  4. Supported account types: Accounts in any organizational directory and personal Microsoft accounts
  5. Redirect URI: Single-page application → paste this page URL
  6. Click Register → copy the Application (client) ID
  7. Go to API permissions → Add → Microsoft Graph → Delegated → add Files.ReadWrite
  8. Paste the ID below and tap Save
